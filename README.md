# Desyatka-bot-v6-deploy

## Restore Base

В проект включён seed-файл `seed_history.json` с актуальной историей и админская кнопка `♻️ Восстановить базу`.

После деплоя:
- открой `/admin`
- нажми `Восстановить базу`
- бот сначала попробует взять свежий snapshot из `snapshots/history_latest.json`
- если snapshot ещё не создан, возьмёт встроенный `seed_history.json`
- игровые таблицы будут очищены и история загрузится заново в `games`

Удобство:
- экран прогноза показывает одно основное число, 2 запасных и реальную точность по базе
- кнопка `🎯 Точность` считает `top-1 / top-3 / чёт-нечёт` прямо из истории, без зависимости от старых логов прогнозов

Автосохранение:
- бот сам сохраняет snapshot полной истории каждые 6 часов
- также стартовый snapshot создаётся при запуске приложения

Локально можно сделать то же самое через:

```bash
python import_history.py "seed_history.json" --truncate
```
